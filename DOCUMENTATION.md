# LA-NN: Liquid-Attention Neural Network for Real-Time ECG Analysis
Documentation for the implementation of a hybrid LNN-Attention architecture for cardiac anomaly detection.

---

## 1. System Overview
The LA-NN project is designed to detect cardiac arrhythmias in real-time. It combines the temporal dynamics of **Liquid Neural Networks (LNNs)** with the global context capabilities of **Multi-Head Self-Attention**.

### High-Level Flow:
1.  **Data Ingestion**: Raw ECG signals (MIT-BIH dataset) are loaded and preprocessed.
2.  **Preprocessing**: Signals are segmented around R-peaks (detected via annotations) and Z-score normalized.
3.  **LNN Encoder**: Segments are passed through Liquid Time-Constant (LTC) cells which model the continuous-time dynamics of the signal.
4.  **Attention Block**: The temporal features from LNN are refined using Multi-Head Attention with Positional Encoding to capture long-range dependencies.
5.  **Classification**: Features are aggregated and passed through a linear layer to classify into AAMI categories (N, S, V, F, Q).
6.  **Clinical Logic**: Output probabilities are processed through a tiered alert system (Normal, Monitor, Alarm).

## 2. Core Architecture

### **Liquid Neural Network (LNN)**
Located in `src/models/lnn.py`.
- **LiquidTimeConstantCell**: Implements the ODE-based LTC cell.
  - Evolves hidden state $h$ based on the formula: $\frac{dh}{dt} = \frac{-h + f(x, h)}{\tau(x, h)}$.
  - Uses Euler integration across defined `ode_steps`.
- **LNNEncoder**: A multi-layer wrapper for LTC cells that processes sequential data.

### **Attention Block**
Located in `src/models/attention.py`.
- **PositionalEncoding**: Adds sinusoidal positional information to the sequence.
- **MultiHeadAttentionBlock**: Implements a standard Transformer-style attention block with LayerNorm and Feed-Forward Networks (FFN).

### **LA-NN Assembly**
Located in `src/models/la_nn.py`.
- **LANN**: The main model class uniting the LNN encoder, the attention block, and the classification head.

## 3. Module Reference

### **`src/config.py`**
Centralized configuration class `Config`.
- **Paths**: `DATA_DIR`, `MODELS_DIR`, `LOGS_DIR`.
- **Hyperparameters**: `HIDDEN_DIM`, `ODE_STEPS`, `NUM_ATTENTION_HEADS`, `LEARNING_RATE`, etc.
- **Decision Thresholds**: `THETA_NORMAL`, `THETA_CRITICAL`.

### **`src/data/preprocessing.py`**
Handles data acquisition and beat extraction.
- `AAMI_MAPPING`: Dictionary mapping MIT-BIH symbols to AAMI classes.
- `ECGDataset`: PyTorch Dataset wrapper.
- `process_record()`: Extracts windows around R-peaks from WFDB records.
- `load_data()`: Orchestrates downloading, processing, and splitting data into Train/Val/Test loaders.

### **`src/training/trainer.py`**
The `Trainer` class handles the training lifecycle.
- **Balanced Weights**: Implements class weighting in Cross-Entropy Loss to handle data imbalance.
- **Logging**: Saves training logs to `.log` and metrics to `.csv`.
- **Optimization**: Uses `AdamW` and `CosineAnnealingWarmRestarts` scheduler.
- **Checkpoints**: Automatically saves the best model based on validation accuracy.

### **`src/evaluation/metrics.py`**
Post-training evaluation.
- `evaluate_model()`: Generates classification reports and confusion matrix data.
- `apply_decision_logic()`: Simulates the tiered clinical alert system on test data.

### **`src/api/stream_engine.py`**
Backend for real-time demonstrations.
- `ECGStreamEngine`: Simulates a live ECG feed by reading from records sample-by-sample.
- `run_inference()`: Extracts a window around a detected peak and runs the model mid-stream.
- `get_alert_level()`: Implements the real-time clinical logic.
